## 1. Анализ финансирования стартапов

**Задача:** исследовать исторические данные о стартапах и финансировании, чтобы определить перспективное направление для дальнейшего инвестиционного анализа.

В ходе проекта я:

- провела первичный анализ и очистку исходных данных;
- обработала пропуски, дубликаты и некорректные типы данных;
- исследовала длительность и количество раундов финансирования;
- разделила рынки на массовые, средние и нишевые сегменты;
- выявила аномальные значения методом IQR отдельно внутри рыночных сегментов;
- сравнила объёмы и распространённость разных типов финансирования;
- изучила динамику инвестиционных раундов по годам;
- проанализировала изменение объёмов финансирования в массовых сегментах;
- сравнила возвраты средств по различным типам финансирования.

После предобработки для анализа осталось более **40 тыс. наблюдений**.  
Исследование показало, что около **59% компаний получили только один раунд финансирования**, при этом компании с периодом привлечения инвестиций более года аккумулировали около **62% общего объёма капитала**.

Также были выделены растущие рыночные направления. На основании динамики финансирования сегментов и анализа типов инвестиций для дальнейшего изучения было выбрано сочетание **Medical + venture**.

> Результат проекта представляет собой направление для дальнейшего инвестиционного анализа, а не готовое инвестиционное решение.

**Стек:** `Python`, `pandas`, `NumPy`, `Matplotlib`, `Seaborn`, `Jupyter Notebook`

## 2. SQL-анализ музыкального стримингового сервиса

**Задача:** исследовать данные музыкального стримингового сервиса с помощью SQL, проанализировать пользовательскую активность, популярность контента и региональные особенности музыкальных предпочтений.

В ходе проекта я:

- работала с реляционной базой данных, содержащей информацию об исполнителях, альбомах, песнях, жанрах и истории прослушиваний;
- объединяла данные из нескольких таблиц с помощью `JOIN`;
- использовала агрегатные функции и `GROUP BY`;
- применяла `CTE` для построения многоэтапных запросов;
- использовала оконную функцию `NTILE()` для выделения наиболее популярных композиций;
- определила наиболее прослушиваемый Rock-альбом;
- выявила исполнителя с наибольшим количеством песен среди топ-20% наиболее прослушиваемых композиций;
- исследовала музыкальные коллаборации;
- проанализировала динамику прослушиваний по месяцам;
- сравнила популярность музыкальных жанров в разных регионах;
- подготовила отдельный аналитический отчёт с интерпретацией результатов.

Анализ показал, что наиболее прослушиваемым Rock-альбомом в исследуемой выборке является **Night Visions — Imagine Dragons**, а **Depeche Mode** имеет наибольшее количество композиций среди топ-20% наиболее прослушиваемых треков. Альбом **Take Care — Drake** содержит максимальное количество совместных композиций. Также были выявлены различия музыкальных предпочтений пользователей между регионами.

По результатам исследования сформулированы продуктовые гипотезы и рекомендации по развитию персональных рекомендаций, региональных музыкальных подборок и маркетинговых активностей.

> Полученные закономерности относятся к исследуемому датасету и используются как основа для дальнейшего продуктового анализа.

**Стек:** `SQL`, `DBeaver`
