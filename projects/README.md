## 1. Анализ финансирования стартапов

**Задача:** исследовать исторические данные о стартапах и финансировании, чтобы определить перспективное направление для дальнейшего инвестиционного анализа.

В ходе проекта я:

- провела первичный анализ и очистку исходных данных;
- обработала пропуски, дубликаты и некорректные типы данных;
- исследовала длительность и количество раундов финансирования;
- разделила рынки на массовые, средние и нишевые сегменты;
- выявила аномальные значения методом IQR отдельно внутри рыночных сегментов;
- сравнила объёмы и распространённость разных типов финансирования;
- изучила динамику инвестиционных раундов по годам;
- проанализировала изменение объёмов финансирования в массовых сегментах;
- сравнила возвраты средств по различным типам финансирования.

После предобработки для анализа осталось более **40 тыс. наблюдений**.  
Исследование показало, что около **59% компаний получили только один раунд финансирования**, при этом компании с периодом привлечения инвестиций более года аккумулировали около **62% общего объёма капитала**.

Также были выделены растущие рыночные направления. На основании динамики финансирования сегментов и анализа типов инвестиций для дальнейшего изучения было выбрано сочетание **Medical + venture**.

> Результат проекта представляет собой направление для дальнейшего инвестиционного анализа, а не готовое инвестиционное решение.

**Стек:** `Python`, `pandas`, `NumPy`, `Matplotlib`, `Seaborn`, `Jupyter Notebook`
